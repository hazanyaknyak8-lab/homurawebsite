Getting started

Homura starts working as soon as it joins your server. These three steps give you the best results.

  1. Add Homura to your serverUse the invite link from the support server, or run invite in any server that already has Homura.
  2. Move Homura’s role upOpen Server Settings, then Roles, and drag Homura’s role near the top. Homura can only act on members whose highest role is below its own. If its role sits at the bottom, bans, mutes and role commands will fail.
  3. Open the help menuRun help. It lists every category. You can also come back to this page and use the command list above.

Prefix and slash

You can run most commands two ways. Type the prefix before the command, like ping, or type / and pick the command from the Discord menu. Both do the same thing.

The default prefix is . You can change it per server with setprefix, for example setprefix !, and go back with resetprefix. Forgot it? Run prefix. Type your own prefix in the box on the command list and every example on this page updates.

Many commands have a shorter alias. ban and hackban are the same command. Two commands are slash only: /security-panel and /extra-owner.

Quick setup

Do these in order the first time. It takes about ten minutes. Steps marked as owner only must be run by the server owner or an extra owner.

  1. Turn on antinuke (owner only)Run antinuke setup, or antinuke wizard if you want to be guided step by step. This protects you if someone with permissions starts deleting channels or banning members.
  2. Whitelist people you trustRun whitelist @user for your head admins and trusted bots so security never blocks them.
  3. Set up logsRun log setup so joins, edits, deletes and role changes are recorded. Also pick an alert channel with antinuke logchannel.
  4. Turn on antiraid (owner only)Run antiraid setup. It watches for many accounts joining at once and can lock the server for you.
  5. Turn on automodRun automod enable, then automod rules to see what it can catch and automod manage to choose.
  6. Welcome your membersRun welcome to see the options and welcome variables to see what you can put in the message, like the member’s name.
  7. Make a backup (owner only, Premium)Backups need Premium. Run backup create. If anything ever goes wrong, you can rebuild from it.

If a raid is happening right now

Run antiraid panic to lock everything at once. If you only need channels locked, lockall does that. When it is over, use antiraid unpanic and unlockall to reopen the server.

Antinuke blocked one of your admins? That is normal if they changed many things quickly. Add them with whitelist @user and it will leave them alone.

Moderation guide

Warnings that escalate

Warn members, and let Homura punish them automatically after a set number of warnings.

Jail instead of ban

Jail keeps someone in a single channel while you decide. Run the setup once first.

jailsetupjail @userunjail @user

Clean up messages

Delete the last few messages, or only the ones from one person, with images, or from bots.

clear 50clearuser @userclearbots

Look back at what happened

See everything done to a member, then open one case to read the details.

modlogs @usercase 12snipe

Server tools

Tickets

Members click a button and get a private channel with your staff. Run ticket setup, then ticket post to place the button in a channel.

Welcome and farewell

Greet people when they join and say goodbye when they leave. Use welcome and farewell setup, then test to preview.

Autorole

Give new members a role automatically, with different roles for humans and bots. Try autorole humans add @Member.

Reaction roles

Let members pick their own roles by reacting to a message. Use reactionrole add.

Auto responders

Make Homura reply when someone says a word or phrase. Use autoresponder add.

Sticky messages

Keep a message, like your rules, at the bottom of a channel. Start with sticky and use stickyhelp for the rest.

Join to create voice

Members join one voice channel and get their own temporary room. Set it up with j2csetup.

Vanity role

Reward members who show your server’s vanity link in their status. Open vanityrole panel.

Levels, giveaways, music

Levels, messages and invites

Members earn XP by chatting. Check yours with levels and see the top members with leaderboard. messages shows message counts and invites shows how many people someone invited. Stop a channel from counting with blacklistchannel #channel.

Giveaways

Run giveaway gpanel to open the panel, or start one directly with giveaway gstart. End early with giveaway gend and pick a new winner with giveaway greroll.

Music

Join a voice channel first, then run play song name. Control it with pause, resume, skip, queue, loop and volume 80. Save your favorites with playlist save. Premium servers can keep Homura in the channel all day with 247 and use karaoke. You can also link fm (Last.fm) and spotify to see and play your own listening.

Troubleshooting

Homura does not answer my commands

Try /ping. If the slash command works but the prefix does not, the prefix was changed (run prefix to check) or the channel is ignored (run ignorelist). Also make sure Homura can see and send messages in that channel.

I get a missing permissions error

Almost always the role order. Drag Homura’s role above the roles it needs to manage, and make sure it has the Discord permission for the action, like Ban Members.

Slash commands do not show up

Reinvite Homura with the slash commands option enabled, then refresh Discord with Ctrl + R on desktop or restart the app on mobile. New commands can take a few minutes to appear.

I cannot use a command tagged Server owner

Only the server owner and extra owners can run those. If you are a co-owner, ask the server owner to add you with /extra-owner add.

Music does not play

Join a voice channel first, and check that Homura has Connect and Speak permission there. If it still stays silent, run join, then play again.
