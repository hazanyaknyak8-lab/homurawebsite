Privacy Policy

Last updated: November 14, 2026

1. Who we are

Homura (“the bot”, “we”, “us”) is a Discord bot for server security, moderation, and community management, run by an independent developer. This policy explains what data the bot handles, why, and what choices you have. By adding or using Homura you agree to this policy.

2. Data we handle

Homura only handles data needed to run the features a server turns on:

  • Identifiers: user IDs, server IDs, channel IDs, role IDs, usernames, and avatars shown by commands.
  • Server settings: prefixes, enabled features, log channels, whitelists, welcome and autorole settings, autoresponders, and similar configuration.
  • Moderation data: warnings, cases, mutes, jail status, and the reasons moderators enter.
  • Activity counts: XP and levels, message counts, and invite tracking. These are counts, not message text.
  • Join information: user ID, username, account age, and join time, used for verification, anti-raid, and anti-nuke checks.
  • Backups: when a premium server runs backup, we save its roles, channels, and settings structure so it can be rebuilt.
  • Feature data: tickets, giveaways, reaction roles, sticky messages, playlists, and any account you choose to link, such as Last.fm or Spotify.

3. Message content and LinkScan

Homura uses Discord’s Message Content intent to read messages in servers where moderation and security features are enabled. Messages are read to run automod, LinkScan, anti-raid and honeypot detection, autoresponders, leveling, and prefix commands. Message text is processed to perform these checks and is not kept, except where a feature you enable needs it, such as an autoresponder trigger or a moderation log entry posted to that server’s log channel.

LinkScan extracts links from messages and checks them against Google Safe Browsing and VirusTotal. Only the URL is sent to these services. We do not send the full message or the author’s identity. If a link is malicious, the message is deleted, the sender may be timed out, and the action is logged for the server’s staff.

4. How we use data

We use data only to provide and secure the features above, to prevent abuse, and to fix bugs. We do not sell data, we do not use it for advertising or profiling, and we do not use it to train AI models.

5. Third parties

Data is shared only with the services needed to run the bot: Discord (the platform the bot runs on), Google Safe Browsing and VirusTotal (URLs only, for LinkScan), our hosting provider, and Last.fm or Spotify if a user chooses to link those accounts. This website also loads the developer’s public Discord profile through Lanyard, and stores a display preference in your browser’s local storage. We do not share data with anyone else except when required by law.

6. Retention and deletion

Server data is kept while Homura is in the server. When the bot is removed from a server, that server’s data is deleted within 30 days. Cached link scan results are kept for a short time to avoid repeated lookups. Server owners and users can ask us to delete their data at any time through the contact options below.

7. Security

Data is stored on private infrastructure with access limited to the developer. No system is perfectly secure, but we take reasonable steps to protect the data we hold.

8. Children

Homura is intended for Discord users, who must meet Discord’s minimum age requirement. We do not knowingly collect data from anyone below that age.

9. Changes

We may update this policy. The date above shows when it last changed. Continued use of the bot after a change means you accept the updated policy.
